Self-produced Fedora RPMs, organized by release version. Packages are unsigned.

  • ai-custom-infra — binary RPMs (packages)
  • ai-custom-infra-source — source RPMs (packages)
  • ai-custom-infra-debuginfo — debuginfo/debugsource RPMs (packages)

Install: download ai-custom-infra.repo and drop it into /etc/yum.repos.d/, then run sudo dnf makecache.
