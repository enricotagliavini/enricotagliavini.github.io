# AGENTS.md

Project: GitHub Pages site hosting a self-produced DNF RPM repository
(`ai-custom-infra`, Fedora based). Hobby project; optimize for **minimal
maintenance and dependability** — reliable, few moving parts, no third-party
CI actions.

## Layout

- `web/` — static site content; the workflow copies it verbatim to the site root.
  Add files here freely; the deploy workflow never needs changes.
- `scripts/package-repo.sh <dnf-repo-dir> <version>` — local packaging
  (options: `-o/--output-dir`, `-h/--help`; see script header for the contract).
- `scripts/publish-release.sh <version> [tarball]` — creates the GitHub release
  (options: `-n/--notes`, `-h/--help`; see script header for the contract).
- `.github/workflows/deploy.yml` — the only CI. Deploys `web/` + the release
  asset to GitHub Pages (Pages source must stay "GitHub Actions"; published
  via `actions/deploy-pages`).
- `dist/` — tarball output (gitignored, never committed).

## Hard constraints (do not break)

1. **Never commit RPMs or tarballs.** GitHub rejects files >100 MB; the largest
   RPM is 121 MB. Binary payloads live only as release assets.
2. **The Pages site is 100% generated by `deploy.yml`.** Do not create or push
   a `gh-pages` branch, and do not edit the deployed site directly — the next
   deploy replaces everything. The Pages source in the repo settings must stay
   on "GitHub Actions".
3. **The URL `/repositories/ai-custom-infra/` is a public contract.** Do not
   rename the path, nest a version into it, or change the archive layout:
   the tarball must contain the DNF repo at the **archive root**
   (`repodata/…`, `lemonade/…rpm`, …) because `repodata/repomd.xml` references
   repo-relative paths.
4. **Release naming:** tag `ai-custom-infra-<version>`, asset
   `ai-custom-infra-<version>.tar.zst`. The workflow matches the asset by
   `ai-custom-infra-*.tar.zst`.
5. Keep CI dependency-free: only first-party `actions/*` (checkout,
   upload-pages-artifact, deploy-pages) + preinstalled runner tools (`gh`,
   `zstd`, `tar`). Do not add third-party actions.
6. **The `github-pages` environment must have no deployment branch policy**
   (Settings → Environments → github-pages → "Any branch and tag"). Release
   runs execute on the release TAG; a branch-restricting policy rejects them
   with "not allowed to deploy to github-pages". If release deploys start
   failing, check this first.

## Canonical update flow (run locally, needs `gh` authenticated)

```sh
./scripts/package-repo.sh path/to/repo 1.1.0    # → dist/ai-custom-infra-1.1.0.tar.zst
./scripts/publish-release.sh 1.1.0     # → release ai-custom-infra-1.1.0 (triggers pipeline)
```

- `package-repo.sh` stages a copy of the repo dir, regenerates repodata with
  `createrepo_c` (MUST — otherwise new RPMs are invisible to dnf), verifies
  `repodata/repomd.xml` + ≥1 `.rpm`, and writes the zstd tarball. It never
  modifies the input dir.
- `publish-release.sh` fails hard if the tag already exists: bump the version.
- The pipeline runs on `release: published` (NOT `created` — a release created
  already-published fires `published`) and `push: main` (push redeploys `web/`
  with the latest release asset; with no release yet, static-only).

## Verifying a package locally (before publishing)

```sh
# tarball structure: repo at archive root
zstd -dc dist/ai-custom-infra-1.0.0.tar.zst | tar -t | head        # expect repodata/ … at top
# dnf can read the staged repo
dnf --disablerepo='*' --repofrompath=aci,<staged-dir> repoquery -l
# live check after deploy (Pages takes ~1 min to propagate)
curl -fsS https://enricotagliavini.github.io/repositories/ai-custom-infra/repodata/repomd.xml
dnf --disablerepo='*' --repofrompath=aci,https://enricotagliavini.github.io/repositories/ai-custom-infra/ repoquery -l
```

## Client install contract (keep in sync with `web/index.html` and README.md)

```ini
[ai-custom-infra]
name=AI Custom Infra
baseurl=https://enricotagliavini.github.io/repositories/ai-custom-infra/
enabled=1
gpgcheck=0
```

Packages are unsigned. If GPG signing is introduced, all three places
(`web/index.html`, `README.md`, this file) must change together.
